# PrivacyWarden Legacy Companion Repository

## Status

This public repository preserves the historical **v3.x** PrivacyWarden source, documentation, and release history. It is a companion archive, not the current production hardening collection.

The active public tool is [privwarden.org/tool](https://privwarden.org/tool). The active source and official signed release material belong to [Gearlight-Labs/privacywarden-files](https://github.com/Gearlight-Labs/privacywarden-files). The v5.2 command-review release must be verified through its published tag, detached signature, public key, and checksums before it is treated as an official artifact.

## Safety boundary

Historical scripts and collection references here can describe Windows settings, profile counts, compatibility assumptions, or deployment methods that no longer match the active reviewed collection. They must not be used as a current one-command installation path.

The historical encrypted collection artifact has been removed from the current default branch and is ignored going forward. It is not the active production collection. Private production blobs, encryption keys, deployment-local state, and mutable VPS artifacts are not part of this repository or any public release export.

## Official release identity

Only releases from the official `Gearlight-Labs` repositories and the `privwarden.org` deployment are official PrivacyWarden material. Existing license terms allow public forks, but forks, modified copies, and reposted archives are not official releases unless the project owners publish them through the official repositories with the documented release integrity material.

## Maintenance policy

The project may retain this repository for historical source, attribution, issues that concern v3.x behavior, and migration reference. New hardening recommendations, current compatibility claims, production collection changes, and signed releases belong to the active project repository.
