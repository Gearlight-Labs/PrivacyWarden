Nothing leaves your machine. Ever.

PrivacyWarden only talks to the Mullvad CLI already on your PC. No analytics, no crash reports, no pinging home. I built this because I was worried about my own privacy — adding telemetry would completely defeat the point.

What it actually does

The stuff that matters.

I built this to solve my own problem. These are the things it does.

🔄

Auto VPN on/off

Detects when OBS starts, turns the VPN off. OBS closes, VPN comes back on. You never touch it.

🛡️

DNS stays locked

Even when the VPN is off during a stream, your DNS is still locked to Mullvad. Your ISP can't see what you're doing.

🔍

Watches for sketchy stuff

Logs unknown processes touching your browser credentials, new network adapters, packet capture tools, config changes. Your personal black box.

📋

Tamper-proof logs

Every log entry is part of a cryptographic chain. If someone edits the log file after the fact, the chain breaks and you'll know.

⚠️

Alerts when things go wrong

Suspicious process, rogue adapter, binary replaced — it escalates to CRITICAL and writes it to the threat log. You'll have a record.

🔧

Tries to fix itself

If DNS gets changed by something else, it puts it back. If the VPN drops unexpectedly, it tries to reconnect. If it can't, it logs exactly why.

Under the hood

What happens after you install it.

It's a Windows background service. Here's the sequence from boot to stream.

Boots with Windows

It's a registered Windows service — starts automatically on boot, no shortcut to click, nothing to remember.

Takes a snapshot

On startup it hashes the Mullvad binary, the config file, and itself. If any of those change later, it flags it immediately.

Watches for OBS

Polls for OBS and other streaming apps every few seconds. Goes live → VPN off. Goes offline → VPN back on.

Keeps checking DNS

Every few minutes it verifies DNS is still locked. If something changed it, it fixes it and writes what happened to the log.

Logs everything

Three log files per day in plain English. Cryptographic chain in a sidecar file proves they haven't been edited.

Escalates threats

Unknown process, rogue adapter, binary swap — each one gets logged with severity. CRITICAL events show up in the tray icon.

Get it running

Install.

Grab the installer, run it as admin, done. Or use the ZIP if you want to see what's happening.

⬇  Installer (easiest)

  1. Download PrivacyWarden-Setup-v1.1.1.exe
  2. Run it as Administrator
  3. Make sure Mullvad VPN is installed first
  4. That's it — it starts automatically

📦  Manual (ZIP)

  1. Download PrivacyWarden-v1.1.1-release.zip
  2. Extract it anywhere
  3. Open PowerShell as Administrator
  4. Run .\Install-PrivacyWarden.ps1

✅  Verify it's working

  1. Open PowerShell as Administrator
  2. Run .\Verify-SecurityAudit.ps1
  3. Check the tray icon in your system tray
  4. Check C:\ProgramData\PrivacyWarden\Logs\
Requirements:  Windows 10/11 Pro or higher  ·  Administrator rights  ·  Mullvad VPN installed

Questions

FAQ.

Honest answers. No marketing speak.

Is this actually useful or is it pointless?

It solves one specific problem: you go offline, forget to turn the VPN back on, and your real IP is exposed for hours without you noticing. PrivacyWarden handles that automatically. If you've never done that — great, you don't need it. If you have, or you're worried about it, this is the fix.

The threat detection and audit logs are extras. They're there if you ever get hit by a social engineering attack or need to prove what was happening on your machine at a specific time. Most people will never need them. But they're there if you do.

Does this work with any VPN?

No. It's built specifically for Mullvad VPN and uses the Mullvad CLI directly. Other VPNs (NordVPN, ExpressVPN, ProtonVPN, etc.) won't work. Mullvad support was chosen because it's privacy-first, has a proper CLI, and is popular in the streamer/VTuber space. Support for other VPNs may come in a future version.

Do I need a Mullvad subscription?

Yes, for the VPN part. The DNS lock works without an active subscription, but Privacy Mode (VPN on) needs a valid Mullvad account with time on it.

Will this slow down my stream?

No. When OBS (or any supported streaming app) is detected, the VPN turns off automatically. You stream at full native speed. DNS lock has no measurable impact on latency.

What streaming apps does it support?

OBS Studio, Streamlabs, XSplit, StreamElements OBS Live, and Prism Live Studio by default. You can add others in config.json by adding the process name to streamingProcessNames.

Does this collect any data?

No. Zero telemetry, no analytics, no crash reporting to external servers. Everything stays on your machine. The logs are yours and only yours. The only thing PrivacyWarden talks to is the Mullvad CLI already installed on your PC.

What does the threat monitor actually watch?

New executables appearing in temp folders, unknown processes accessing browser credentials, unknown processes making outbound network connections, config file changes, new network adapters, and packet capture tools. It only watches your own machine — no traffic capture, no logging of what websites you visit.

Where are the logs?

C:\ProgramData\PrivacyWarden\Logs\ — three files per day: _service.log, _session.log, and _threat.log. Open File Explorer and type the path directly into the address bar (ProgramData is hidden by default). They're plain text — open them in Notepad.

Windows SmartScreen is blocking the installer. Is it safe?

Yes. Click "More info" then "Run anyway". PrivacyWarden is a private indie tool without a corporate code signing certificate (those cost $300+/year). The SHA256 hash in SHA256.txt lets you verify the file is genuine. The full source code is on GitHub if you want to check exactly what it does before running it.

VirusTotal shows 1/71 flagged — is the installer malware?

No. The one flag is CrowdStrike's heuristic ML model at 60% confidence — below their own threshold for a real detection. Every other vendor (Microsoft, Kaspersky, ESET, Sophos, Malwarebytes, SentinelOne, and 65+ others) says clean.

Heuristic scanners flag PrivacyWarden because it does things that look suspicious in isolation: installs a Windows Service, spawns mullvad.exe as a subprocess, modifies DNS settings, and auto-starts a tray app on login. That's exactly what it's supposed to do. The installer also isn't signed with a commercial CA certificate (those cost $200–400/year), which makes ML models nervous.

If you want to verify it yourself: the full source code is public on GitHub, the SHA256 hash is in SHA256.txt in the release, and you can build it from source using the compilation guide.

The tray icon isn't showing.

Run PrivacyWardenTray.exe manually from C:\Program Files\PrivacyWarden\PrivacyWardenTray.exe. If it still doesn't appear, check that it's in your startup apps (Task Manager → Startup apps tab).

The service won't start.

Open services.msc, find PrivacyWarden, and check the status. If it failed, check Windows Event Log → Applications for the error message. Make sure Mullvad VPN is installed — PrivacyWarden won't start without it.
