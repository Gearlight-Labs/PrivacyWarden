## [1.0.0] - 2026-05-30

**Initial Release**

Finally releasing this thing. Here's what's included:

### Core Features
- Automatic VPN mode switching (Privacy/Streaming)
- Real-time DNS leak detection (4-layer system)
- Continuous background monitoring as Windows Service
- Legal defense audit trail with timestamped logging
- Cryptographic hardening (TLS 1.2/1.3)
- Fail-safe mechanisms and automatic recovery

### What Works
- ✅ Mullvad VPN integration
- ✅ DNS lock enforcement
- ✅ Kill switch on VPN failure
- ✅ Secure file logging
- ✅ Windows Event Log integration
- ✅ Input validation and command whitelisting

- ✅ USER_GUIDE.md - Full walkthrough
