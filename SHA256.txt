## How to Verify

On Windows PowerShell:
```powershell
Get-FileHash -Path "path\to\file" -Algorithm SHA256
```

On Linux/Mac:
```bash
sha256sum path/to/file
```

Compare the output with the hash listed above. If they match exactly, the file is intact and hasn't been corrupted or tampered with.

## Security Notes

- These hashes verify **file integrity** only (corruption detection during download)
- They do NOT verify authenticity (that the file came from Aya Yoki)
- For full security, check the PGP signature on the GitHub release (future enhancement)
- Always download from the official GitHub repository: github.com/Gearlight-Labs/VTuberVPNService

## What to Do After Verification

1. Extract the source code
2. Open the project in Visual Studio 2022 or later
3. Build the solution: `dotnet build -c Release`
4. The compiled executable will be in `bin/Release/net7.0/`
5. Follow COMPILATION_GUIDE.md for detailed instructions
